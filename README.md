# Rock Paper Scissors

## Description
A simple Rock Paper Scissors game played against the computer through the console. The player selects rock, paper, or scissors, and the computer randomly chooses its own move. The game compares both choices to determine the winner of each round and keeps track of the scores.

This project focuses on practicing JavaScript fundamentals, including functions, conditionals, user input, random number generation, loops, and game logic. A graphical user interface (GUI) will be added in a later version.

## How to Play
1. Run the game.
2. Enter your choice: rock, paper, or scissors.
3. The computer randomly selects its own choice.
4. The game announces the round winner or a tie.
5. Scores are updated accordingly.
6. The game continues until the player decides to stop or the specified number of rounds is completed.

## Rules
- Rock beats scissors.
- Scissors beats paper.
- Paper beats rock.
- If both players choose the same option, the round is a tie.

## Features
- Console-based gameplay.
- Random computer choices.
- Round-by-round winner determination.
- Score tracking for the player and computer.
- Input validation for invalid choices.
