# Rock Paper Scissors Game

## About the Project

This is a simple Rock Paper Scissors game made with JavaScript.

You play against the computer. Both you and the computer choose one of three things:

- Rock
- Paper
- Scissors

The game checks both choices to see who wins each round.

## How to Play

1. Open the project in your browser.
2. Open the browser console.
3. Type your choice when the game asks you.
4. The computer will choose its own option.
5. The winner of each round will be announced in the console.
6. Play 5 rounds to see who wins the game.

## Rules of the Game

- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- If both players choose the same thing, it is a tie.
